Privacy Policy

Last updated: October 18, 2026

Personal Assistant is a privately run tool. Its users are its owner and a small number of people the owner has personally invited. It is not offered to the public.

What is stored

  • For invited users: the phone number and email address used to reach or sign in to the assistant, the courses each person is enrolled in, their practice answers and progress, and any feedback they send.
  • Voice: voice conversations are processed in real time to run the session. The assistant stores the answers and scores from a voice session, not the audio.
  • For the owner: the above, plus personal planning and productivity records, and messages from one Gmail label in the owner's own account.

Gmail

The assistant reads only the owner's own Gmail account, and only one label the owner has set up. It copies those messages into the owner's private database for personal use and marks them as read once stored. It never accesses any other user's email.

Who can see what

Each user's records are kept separate, and invited users cannot see one another's data. The owner administers the system and can access all stored data.

Services that process data

The assistant relies on outside services to run: Supabase (database and hosting), Streamlit (web interface), Anthropic (AI processing), Meta (WhatsApp messaging), Google (Gemini, for voice conversations, on Google's paid API service, under which Google does not use the data to improve its products; Google sign-in, for people who choose it; and Gmail, for the owner's own mailbox only), and VAPI while voice is being moved off it. Each processes data only to provide its part of the service.

Sharing

Data is not sold, shared, or disclosed to anyone beyond the services above. It is not used for advertising.

Use of Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Invited users can ask the owner to delete their data at any time. Google access can be revoked from the Google Account's third-party access settings.
